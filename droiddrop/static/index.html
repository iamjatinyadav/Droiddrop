Connect your Android phone

Pick how you want to connect. Once connected, you can browse, upload and download files.

adb is not installed. The app needs Android platform-tools. Install it, then restart the app:
macOS: brew install --cask android-platform-tools  ·  Windows: winget install Google.PlatformTools  ·  Linux: sudo apt install adb

🔌 USB cable

Fastest. Works on every Android version.

  1. On the phone, open Settings → About phone and tap Build number 7 times to unlock Developer options.
  2. Go to Settings → System → Developer options and turn on USB debugging.
  3. Plug the phone into this computer with a USB cable.
  4. Tap Allow on the phone when it asks "Allow USB debugging?"

The phone appears in the left sidebar automatically.

📶 Wi-Fi

No cable needed. The phone and computer must be on the same Wi-Fi.

  1. Unlock Developer options (same as step 1 on the left).
  2. Android 11+: turn on Wireless debugging in Developer options, then pair with a code.
  3. Older Android: connect once with USB, then click Switch to Wi-Fi next to the device.

🔌 Connect via USB

  1. On the phone, open Settings → About phone and tap Build number 7 times.
  2. Open Settings → System → Developer options and enable USB debugging.
  3. Connect the cable. If the phone asks for a USB mode, any mode works (choose File transfer if unsure).
  4. Tap Allow on the "Allow USB debugging?" popup. Tick "Always allow from this computer" to skip it next time.

Shows as unauthorized? Unlock the phone and look for the popup. Still nothing? Try a different cable — some cables only charge.
